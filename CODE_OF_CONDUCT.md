# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, personal attacks
and discriminatory language are not tolerated.

To report a problem, use GitHub's **Report content** option or contact the maintainers through a private
message on GitHub. Reports are handled confidentially.
