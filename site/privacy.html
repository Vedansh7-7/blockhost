PRIVACY POLICY

BlockHost. Last updated 21 November 2026.

What data BlockHost accesses

With the group owner's permission, BlockHost uses the Google Drive drive.file scope. This gives it access only to files BlockHost itself creates: one folder containing

  • a status file (whether the server is running, which laptop is hosting, its local network address, online player names), and
  • up to two encrypted Minecraft world saves.

BlockHost cannot read, change or delete any other file in your Google Drive.

Where data goes

Data moves only between the group members' own computers and the owner's Google Drive. BlockHost has no server of its own, uses no analytics or tracking, shows no ads, and never sells or shares data with anyone.

World saves are encrypted (AES-256) before upload. Only BlockHost, with the group's password, can decrypt them.

Google API data

BlockHost's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke BlockHost at any time at myaccount.google.com/permissions, and delete the "BlockHost" folder from Google Drive to remove all stored data.
