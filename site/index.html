BLOCKHOST

A private launcher for hosting one shared Minecraft world among friends.

What it does

BlockHost lets a small group of friends take turns hosting the same Minecraft Java world on their home network. The world is kept, encrypted, in the group owner's Google Drive, and a lock makes sure only one laptop hosts at a time.

Google Drive access

BlockHost uses the narrow drive.file permission. It can only see files it created itself (one folder holding the encrypted world and a small status file). It cannot see anything else in your Drive.

Not for public use

BlockHost is a personal, non-commercial tool for one private group. It is not affiliated with Mojang or Microsoft.
